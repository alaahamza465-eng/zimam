# زمام — مدير ذكي لفريقك على واتساب

**Zimam** is a WhatsApp-first AI manager for small teams (5–50 people). Employees never install anything: they check in, post their tasks, and get followed up inside WhatsApp. The manager gets one simple web page with everything that needs a decision.

زمام نظام إدارة مفتوح المصدر للشركات الصغيرة. الموظف ما بينزّل أي تطبيق: بيسجّل حضوره وبيكتب مهامه في قروب واتساب، والبوت بيتابع معه. والمدير عنده صفحة وحدة بسيطة فيها كل اللي يحتاج قرار.

## شو بيعمل

| للموظف (في واتساب) | للمدير (في الواجهة) |
|---|---|
| أول رسالة بالصبح في القروب = تسجيل دخول، ورسالة فيها «خروج» = خروج | مين وصل ومتى، والمتأخرين |
| بيكتب مهامه بنقاط، والبوت بيسأله كم بدو وقت لكل مهمة | مهام كل موظف وحالتها (أُنجزت / جارية / ما أُنجزت) |
| لما يخلص الوقت البوت بيسأل: أنجزت / صار معي مشكلة / بدي وقت | المشاكل والمهام الناقصة بتوصل «يحتاج قرارك» مع السبب |
| تذكير صباحي بمهامه، وتذكير لو ما سجّل دخول | عقوبة أو تمام بضغطة وحدة، ويبلّغه البوت |
| | إسناد مهام، رسائل للفريق، تقارير يومية/أسبوعية، ملخص المساء على واتساب |

بدون Airtable، بدون قواعد بيانات خارجية، بدون اشتراكات. كل شي على سيرفرك.

## التثبيت في 10 دقائق

تحتاج: سيرفر Ubuntu (2GB RAM كافية، مثل Hostinger أو DigitalOcean)، دومين مشاور على السيرفر، ورقم واتساب للبوت (شريحة عادية).

```bash
git clone https://github.com/alaahamza465-eng/zimam.git && cd zimam
bash install.sh
```

المثبّت بيسألك الدومين والمنطقة الزمنية، بيولّد المفاتيح، وبيشغّل كل شي بـ Docker مع HTTPS تلقائي. في الآخر بيطبع لك رابط الواجهة والمفتاح.

بعدها من الواجهة: **فعّل** (الصق المفتاح) ← **اربط واتساب** (امسح الكود من جوال البوت) ← ضيف رقم البوت لقروب الفريق واكتب فيه **زمام حضور**. خلص.

الدليل الكامل بالعربي: [docs/GUIDE-ar.md](docs/GUIDE-ar.md)

## كيف بيشتغل

```
واتساب الفريق ──► WAHA (جلسة واتساب) ──► zimam (Node.js) ──► ملفات JSON على السيرفر
                                               ▲
المدير ◄── الواجهة (ملف HTML واحد) ◄──────────┘ (API محمي بمفتاح)
```

- `server/main.js`: البوت والـ API والتذكيرات. ملف واحد، بدون فريمورك.
- `app/index.html`: واجهة المدير. ملف واحد، تفتح من أي متصفح أو جوال.
- `docker-compose.yml`: WAHA + zimam + Caddy (HTTPS تلقائي).

## الأمان

- المفتاح الإداري بينحفظ في متصفح المدير فقط، وما بينكتب على القرص داخل حالة التطبيق.
- الويبهوك من WAHA موقّع بـ HMAC، والـ API كله خلف HTTPS.
- البوت ما بيرد إلا على أرقام الفريق المسجّلة.
