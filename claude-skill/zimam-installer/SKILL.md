# مثبّت زمام

أنت بتمشّي المستخدم من "عندي سيرفر فاضي" لحد "فريقي شغّال على زمام". الهدف إنه ما يكتب ولا أمر بنفسه إلا إذا كان لازم (مثل إدخال كلمة سر).

## قبل ما تبدأ: افهم وضعه بثلاث أسئلة فقط

اسأل مرة وحدة، لا تكرر:

1. **وين سيرفرك؟** (Hostinger / DigitalOcean / Hetzner / ما عندي سيرفر). لو ما عنده: اقترح أرخص خطة Ubuntu 2GB عند أي مزوّد وارجع بعد ما يشتريها.
2. **شو الدومين؟** لازم دومين أو دومين فرعي مشاور على عنوان السيرفر (سجل A). لو ما عنده دومين، اشرح له إن أغلب المزوّدين بيعطوا دومين فرعي مجاني، أو يشتري واحد رخيص.
3. **كيف بتدخل على السيرفر؟** SSH من جهازه، أو terminal من لوحة المزوّد في المتصفح (Hostinger عندها «وحدة تحكم الويب»).

ما تسأل عن أي شي ثاني. المثبّت بيولّد المفاتيح لحاله.

## طريقة التنفيذ حسب أدواتك

- **لو عندك أداة متصفح (Claude in Chrome / المتصفح المدمج) والمستخدم بيستخدم terminal من لوحة المزوّد:** افتح الـ terminal بنفسك ونفّذ الأوامر مباشرة. اقرأ الناتج بالصورة بعد كل خطوة.
- **لو عندك Bash على جهاز المستخدم وعنده SSH:** نفّذ عبر `ssh root@SERVER`. لو طلب كلمة سر، اطلب من المستخدم يدخلها بنفسه، لا تطلب منه يكتبها لك في المحادثة.
- **لو ما عندك أي أداة تنفيذ:** أعطِ الأوامر كتلة واحدة جاهزة للنسخ، واطلب منه يلصق الناتج.

## خطوات التثبيت

### 1. الملفات على السيرفر

لو المستخدم رفع ملفات المشروع في المحادثة: ارفعها للسيرفر (scp أو الصقها). الأسهل دائماً من GitHub:

```bash
apt update && apt install -y git curl
git clone https://github.com/alaahamza465-eng/zimam.git /opt/zimam && cd /opt/zimam
```

### 2. التثبيت بدون أسئلة

```bash
cd /opt/zimam && DOMAIN=zimam.example.com TZ_NAME=Asia/Riyadh ANTHROPIC_API_KEY= bash install.sh
```

بدّل الدومين والمنطقة الزمنية بقيم المستخدم. المثبّت بيثبّت Docker لو مش موجود، وبيشغّل WAHA + zimam + Caddy، وبيطبع رابط الواجهة والمفتاح.

### 3. تحقق

```bash
docker ps --format '{{.Names}} {{.Status}}'
curl -s https://DOMAIN/health
```

لازم تشوف ثلاث حاويات Up و `{"ok":true}`. لو الدومين ما رد بعد دقيقتين: تأكد من سجل A ومن إن المنفذين 80 و443 مفتوحين بجدار المزوّد.

### 4. سلّم المفتاح وخلّيه يربط واتساب

اطبع للمستخدم:
- رابط الواجهة `https://DOMAIN/app`
- المفتاح من `grep ADMIN_SECRET /opt/zimam/.env`

وبعدها اطلب منه ثلاث خطوات بالترتيب، واستنى "تم" بعد كل وحدة:
1. يفتح الرابط، يضغط «فعّل»، يلصق المفتاح.
2. يضغط «اربط واتساب» ويمسح الكود من جوال البوت (واتساب ← الأجهزة المرتبطة ← ربط جهاز).
3. يضيف رقم البوت لقروب الفريق ويكتب فيه: **زمام حضور**.

### 5. الفريق

اطلب منه أسماء الموظفين وأرقامهم (مع رمز الدولة) ووقت دوام كل واحد، وأدخلهم من الإعدادات ← الفريق، أو اشرح له كيف. ذكّره يحدد طريقة المخاطبة (مذكّر/مؤنّث) لكل موظف حتى يكون كلام البوت صح.

### 6. أول تجربة

اطلب من موظف واحد يكتب في القروب:
```
مهامي اليوم:
1- مهمة تجريبية
```
ويرد على البوت بـ «10 دقائق». بعد 10 دقائق البوت بيسأله، ويرد «1». لو هذا اشتغل، النظام جاهز.

## مشاكل شائعة وحلّها

| العرض | السبب الغالب | الحل |
|---|---|---|
| `curl` على الدومين بيرجع فاضي | DNS لسا ما انتشر أو المنفذ مسكّر | انتظر 5 دقائق، افحص `dig DOMAIN`، افتح 80/443 |
| الواجهة بتقول «المفتاح غلط» | مسافة زيادة أو مفتاح قديم | `grep ADMIN_SECRET .env` وانسخه من جديد |
| «واتساب مفصول» بعد الربط بشوي | الجوال انمسح من الأجهزة المرتبطة | اربط من جديد، وخلّي جوال البوت شغّال |
| البوت ما بيرد في القروب | الرقم مش في الفريق أو القروب مش مربوط | ضيف الرقم بالإعدادات؛ اكتب «زمام حضور» بالقروب |
| `docker compose` مش موجود | Docker قديم | `curl -fsSL https://get.docker.com \| sh` |

## قواعد

- لا تطلب من المستخدم أي كلمة سر أو مفتاح في المحادثة. المفاتيح بتتولّد على السيرفر وبتضل هناك.
- لا تعدّل ملفات المشروع إلا لو طلب، وخلّي التعديل في `.env` أو `server/main.js` بس.
- بعد كل أمر بينفّذ شي على السيرفر، تحقق بأمر قراءة قبل ما تنتقل.
- اختصر: المستخدم غالباً مش مبرمج. جملة لكل خطوة.
