# تثبيت زمام بواسطة Claude

ما بتحتاج تعرف Docker ولا Linux. Claude بيعمل التثبيت وإنت بتراقب.

## المطلوب منك

1. **سيرفر** Ubuntu جديد (2GB RAM) من أي مزوّد، و**دومين فرعي** مشاور عليه. لو مش عارف كيف، قل لـ Claude: «ساعدني أجهز سيرفر ودومين».
2. **رقم واتساب** للبوت على جوال بيضل شغّال.
3. **Claude Desktop** (وضع Cowork) أو **Claude Code**، مع إضافة Claude in Chrome لو بدك Claude يشتغل على terminal المزوّد من المتصفح.

## الخطوات

### 1. ثبّت المهارة

- في Claude Desktop: الإعدادات ← Skills ← Add ← اختر المجلد `claude-skill/zimam-installer` (أو ملف `zimam-installer.skill` من صفحة Releases).
- في Claude Code: انسخ المجلد إلى `~/.claude/skills/zimam-installer`.

### 2. افتح محادثة جديدة واكتب

```
ثبّت زمام. سيرفري على Hostinger، الدومين zimam.mycompany.com، وبدخل عليه من وحدة تحكم الويب.
```

Claude بيسألك بس اللي ما بيقدر يعرفه، وبينفّذ الباقي: تنزيل المشروع، تشغيل المثبّت، التحقق، وبيعطيك رابط الواجهة والمفتاح.

### 3. اربط واتساب

Claude بيقلك متى: افتح الرابط، الصق المفتاح، امسح الكود من جوال البوت، وضيف رقم البوت لقروب الفريق واكتب فيه «زمام حضور».

### 4. أدخل الفريق

أعطِ Claude قائمة الموظفين (الاسم، الرقم مع رمز الدولة، وقت الدوام) وهو بيدخلهم، أو ادخلهم إنت من الإعدادات.

## لو بدك Claude يعدّل النظام

المشروع كله ملفين: `server/main.js` (البوت) و `app/index.html` (الواجهة). ارفعهم في المحادثة وقل شو بدك: «خلّي البوت يسأل عن الأولوية قبل الوقت»، «ضيف نوع عقوبة جديد»، «غيّر وقت الملخص». بعد التعديل: `cd /opt/zimam && docker compose up -d --build`.
