# دليل زمام الكامل

هذا الدليل بيمشّيك من سيرفر فاضي لحد ما يصير فريقك كله شغّال على زمام. اقرأه بالترتيب أول مرة، وبعدها ارجع لأي قسم لما تحتاجه.

## 1. شو تحتاج قبل ما تبدأ

- **سيرفر Linux** (Ubuntu 22 أو 24) بـ 2GB RAM على الأقل. أي مزوّد: Hostinger، DigitalOcean، Hetzner، Contabo. بيكلّف 5–8 دولار بالشهر.
- **دومين أو دومين فرعي** مشاور على السيرفر بسجل A. مثال: `zimam.company.com` → عنوان السيرفر.
- **رقم واتساب للبوت.** شريحة عادية بجوال قديم أو حتى واتساب بزنس. هذا الرقم بيصير "شخصية" زمام أمام الموظفين. ما تستخدم رقمك الشخصي.
- (اختياري) **مفتاح Anthropic** لو بدك البوت يرد على أسئلة الموظفين على الخاص.

## 2. التثبيت

ادخل على السيرفر كـ root (من SSH أو من terminal المزوّد) ونفّذ:

```bash
apt update && apt install -y git
git clone https://github.com/alaahamza465-eng/zimam.git && cd zimam
bash install.sh
```

المثبّت بيسألك ثلاث أسئلة (الدومين، المنطقة الزمنية، مفتاح Anthropic الاختياري) وبيعمل الباقي: تثبيت Docker لو مش موجود، توليد المفاتيح، وتشغيل ثلاث حاويات:

| الحاوية | دورها |
|---|---|
| `zimam-waha` | جلسة واتساب (مشروع WAHA المفتوح) |
| `zimam` | البوت + الـ API + الواجهة |
| `zimam-caddy` | HTTPS تلقائي على الدومين |

في الآخر بيطبع لك:

```
الواجهة:  https://zimam.company.com/app
المفتاح:  3f8a...
```

**احفظ المفتاح.** هو كلمة سر الإدارة. بتقدر تطلعه لاحقاً من `cat .env`.

## 3. الربط الأول (مرة وحدة)

افتح رابط الواجهة من المتصفح. بتلاقي بطاقة «تشغيل زمام: ثلاث خطوات».

1. **فعّل:** الصق المفتاح واضغط «احفظ وافحص».
2. **اربط واتساب:** بيظهر كود QR. من جوال البوت: واتساب ← الإعدادات ← الأجهزة المرتبطة ← ربط جهاز ← امسح الكود. الشاشة بتتسكّر لحالها لما يربط.
3. **اربط قروب الحضور:** ضيف رقم البوت لقروب الفريق على واتساب (أو اعمل قروب جديد اسمه مثلاً «الحضور والمهام»)، واكتب فيه: **زمام حضور**. البوت بيرد إنه بلّش.

بعدها روح للإعدادات ← الفريق، وضيف موظفينك: الاسم، الدور، رقم الواتساب مع رمز الدولة، وقت بداية دوامه، وطريقة المخاطبة (مذكّر/مؤنّث).

## 4. يوم عمل عادي

### عند الموظف

- **الصبح:** يكتب أي رسالة في القروب («صباح الخير»، «وصلت»، صورة). البوت بيحط ✅ وبيسجّل وقت الدخول.
- **المهام:** يكتب مهامه بنقاط:
  ```
  مهامي اليوم:
  1- تصميم بوست العرض
  2- الرد على رسائل العملاء
  3- جدولة ريلز الأسبوع
  ```
  البوت بيسأله: «كم بدك وقت للمهمة 1؟». بيرد «ساعة» أو «30 دقيقة» أو «ساعتين»، أو بيرد عليهم كلهم مرة وحدة: «1 ساعة، 2 نص ساعة، 3 ساعتين».
- **المتابعة:** البوت بيقول «ابدأ بالمهمة 1، برجعلك بعد ساعة». لما يخلص الوقت بيسأل:
  ```
  خلص وقت المهمة 1: تصميم بوست العرض
  شو صار؟
  1 أنجزت
  2 صار معي مشكلة
  3 بدي وقت
  ```
  - `1` → بيبدأ المهمة الجاية.
  - `3` → «كم بدك وقت زيادة؟» وبيرجع بعدها.
  - `2` → «شو المشكلة؟» ← يكتبها ← «تنتقل للجاية (1) ولا تكمل فيها (2)؟». المشكلة بتوصل للمدير.
- لو خلص قبل الوقت بيكتب «أنجزت» وبينتقل فوراً.
- **المساء:** رسالة فيها «خروج» بتسجّل وقت الخروج. أي مهمة ما خلصت لنهاية اليوم بتترفع للمدير تلقائياً.

### عند المدير

افتح الواجهة من الجوال أو اللابتوب. الصفحة الرئيسية فيها:

- **يحتاج قرارك:** المهام اللي ما خلصت مع سبب الموظف، التأخير، الغياب، والمصاريف فوق الحد. كل سطر فيه زرين.
- **عقوبة:** بتفتح لوحة فيها 5 أنواع (تأخير دوام، غياب، تأخير مهمة، مشكلة في العمل، استهتار) بمبلغ جاهز بتقدر تعدّله، وصندوق «بلّغه على واتساب». ضغطة وخلص.
- **تمام:** بتقفل الموضوع بدون عقوبة.
- **الفريق اليوم:** مين وصل ومتى، وشو شغّال عليه كل واحد الآن.
- **خانة الأوامر:** اكتب «مهمة لأحمد اتصال بالعملاء الخميس» أو «إيراد 350 اشتراك» وبيفهم.

الساعة 6 مساءً (بتغيّرها) بيوصلك على واتساب ملخص اليوم: الحضور، المهام، وشو بانتظار قرارك.

## 5. الإعدادات المهمة

| القسم | شو فيه |
|---|---|
| الفريق | إضافة/إيقاف/حذف موظف، رقمه، بداية دوامه، طريقة مخاطبته |
| الدوام والصرف | بداية الدوام العامة، دقائق السماح، حد الصرف بدون موافقة |
| العقوبات | مبلغ كل نوع من الخمسة. 0 يعني تنبيه بدون خصم |
| التذكيرات التلقائية | مهام الصبح، تذكير الدخول، وقت ملخص المساء، نهاية اليوم، ومتابعة المهام في القروب أو على الخاص |
| الأولويات وأهداف الأسبوع | استراتيجيتك: كل مهمة بتنربط بأولوية، والتقرير الأسبوعي بيقارن الفعلي بالهدف |
| البيانات | تنزيل المهام/المالية/الحضور CSV، أو مسح كل شي والبداية من جديد |

بياناتك بتنحفظ على السيرفر، فتفتح الواجهة من أي جهاز وبتلاقي نفس الشي. كل جهاز بيحتاج المفتاح مرة وحدة بس.

## 6. أسئلة شائعة

**هل الموظف لازم ينزّل شي؟** لا. واتساب بس.

**البوت ما رد على رسالة في القروب؟** تأكد إن رقم الموظف مسجّل بالإعدادات بنفس الرقم اللي بيكتب منه (مع رمز الدولة). الأرقام غير المعروفة بتظهر في الإعدادات ← قروب الحضور مع زر «أضفه».

**واتساب انفصل؟** الواجهة بتعرض «واتساب مفصول» مع زر «اربط». امسح الكود من جديد. بيصير لو جوال البوت انطفى فترة طويلة أو انمسح من الأجهزة المرتبطة.

**ممكن المتابعة تكون على الخاص بدل القروب؟** نعم: الإعدادات ← التذكيرات ← «على الخاص».

**كيف أغيّر كلام البوت؟** الرسائل كلها في `server/main.js`، ابحث عن النص وعدّله، وبعدها `docker compose up -d --build`.

**كيف آخذ نسخة احتياطية؟** كل البيانات في volume اسمه `zimam_data`:
```bash
docker run --rm -v zimam_zimam_data:/data -v $(pwd):/backup alpine tar czf /backup/zimam-backup.tgz /data
```

**التحديث لنسخة أحدث:**
```bash
git pull && docker compose up -d --build
```

**الحذف الكامل:**
```bash
docker compose down -v
```

## 7. ملاحظات مهمة

- واتساب ما بيوفّر قوائم منسدلة حقيقية إلا للحسابات الرسمية المدفوعة، فالموظف بيرد بالرقم أو الكلمة. البوت بيفهم «1» و«أنجزت» و«خلصت» و«تم».
- زمام بيستخدم جلسة واتساب عادية عبر WAHA. استخدمه بشكل طبيعي مع فريقك، ولا تستخدمه للرسائل الجماعية لغرباء، حتى ما يتوقف الرقم.
- المفتاح الإداري بيعطي صلاحية كاملة. ما تحطه في أي مكان عام.
